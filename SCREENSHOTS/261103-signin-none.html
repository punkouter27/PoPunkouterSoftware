Sign-in: "None" instead of a dash

  1. Before: a web app with no sign-in in the catalog showed "–", which reads as "not known".
  2. After: it says None. To remove login from an app, delete its signIn line in apps.json; any leftover sign-in hint is dropped too, so the cell can't contradict itself.
  3. The games have no backend, so they still have no Sign-in column. If every web app drops login, the shared line says "Sign-in None".

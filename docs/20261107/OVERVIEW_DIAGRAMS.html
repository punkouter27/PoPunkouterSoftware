Three plates that explain the whole system

The same facts as the other reports, redrawn as editorial diagrams following the diagram-design method: one idea per node, nine nodes at most, right-angle connectors, and one or two coral accents for what matters most.

If you only look at one page, look at these three pictures: where things live, what happens when you press Rescan, and the locks between a stranger and the data.

Method notes: types chosen from the skill's guide (Architecture, Sequence, Layer stack); default style-guide tokens kept (paper #f5f5f5, ink #2d3142, accent #bf4520) because this repo has no diagram brand profile; geometry on a 4px grid. The skill was read from its repository, not installed.

Plate 1 · Architecture · nine nodes

Everything goes through one host

Pages read the filing cabinet; only the scan talks to Azure.

The host is the only doorBrowser files and JSON come from one origin, so there is no CORS to configure and the CSP can say 'self'.
Dashed boxes are not oursShared or third-party services. Each one can be down; the host degrades instead of failing.

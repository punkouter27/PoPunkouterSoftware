# .NET Blazor Apps & Games — Shared Standards

This folder holds shared architecture, UI, testing, and deployment conventions across all `.NET` / Blazor projects in `_CODEMATT`.

## Scope
- Blazor Server / WebAssembly / Hybrid project layout & component patterns
- Shared CSS / dark-theme tokens, responsive layout, and accessibility rules
- Automated testing (xUnit / bUnit / Playwright) & GitHub Actions CI templates
- Deployment & live URL conventions tracked by `GLOBAL/station/pages/fleet_health.html` and `readiness.html`
